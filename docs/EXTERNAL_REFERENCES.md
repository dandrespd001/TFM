# Referencias externas necesarias para una auditoría VIU completa

Los siguientes archivos institucionales forman parte del proyecto local original, pero no se republican en este repositorio. Para que GPT Work pueda comprobar fielmente estructura, formato y criterios académicos, el autor debe adjuntarlos o conectarlos en el espacio de trabajo autorizado:

1. `P11_06_F08b Plantilla TFT individual_v02 (nc)(1).docx` — plantilla oficial y primera autoridad de composición.
2. `3. Normas APA_VIU_7ed.pdf` — adaptación institucional de APA 7.
3. `Tutoria 5_Normas APA.pptx` — orientaciones de citación y referencias.
4. `Tutoria 3_Escritura académica(1).pdf` — recomendaciones de redacción académica.
5. `11MERR_10_A_2025-26 Tutoria Inicial.pdf` — marco general del TFM del máster.
6. `Anexo I Solicitud TFM -MERR-VIU_v2-Rev3Junio26.docx` — alcance y objetivos aprobados.
7. `TFM_Borrador_v1/TFM_San_Andres_APA_VIU_Diomar_Andres_Pacheco_D.docx` — referencia prioritaria del autor para Introducción, Objetivos y Marco teórico.

## Prioridad cuando existen discrepancias

1. Plantilla y documentación oficial VIU.
2. Alcance y objetivos formalmente aprobados.
3. Borrador V1 para la primera parte ya revisada.
4. V4 como texto académico actual.
5. Evidencia reproducible V2–V4 para cifras y resultados.
6. Fuentes científicas y oficiales verificadas.

No debe inferirse que el repositorio, por sí solo, acredita conformidad formal con todos los requisitos VIU. Si un documento externo no se adjunta, el resultado correspondiente debe marcarse como pendiente de verificación y no como aprobado.
